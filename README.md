# 광석 포도책방

광석초등학교 **문학상 수상작 함께 읽기** 페이지입니다.

- 주소: https://cosan75.github.io/podo-bookshop/
- 학년별 수상작 19권 · 책 소개와 함께 나눌 질문
- 학교도서관 서가 번호 안내 · 알라딘/교보문고/YES24 링크
- 한줄평 쓰기 · 포도알 10개를 모으면 포도송이 상장
- 한줄평과 포도알은 각자 쓰는 기기의 브라우저에 저장됩니다.

## 학교도서관 소장 목록 연결
이 폴더에 `catalog.json`을 두면 검색창에서 광석초 도서관 책과 청구기호가 함께 나옵니다.

```json
{"updatedAt": 0, "rows": [["서명", "저자", "출판사", "청구기호"]]}
```
